Sobre el libro

Descubre Microsoft Fabric, la nueva plataforma de datos de Microsoft que amplía las capacidades de Power BI y además permite procesar e integrar datos de una manera totalmente innovadora mediante el concepto de Inteligencia Generativa.

Basado en los mismos principios que hicieron exitoso a Power BI, Microsoft Fabric incorpora capacidades avanzadas de datos en un entorno completamente integrado que simplifica la Analítica, la Ciencia de Datos y la Inteligencia Generativa.

Este libro te guía paso a paso, desde los conceptos clave, su interfaz de usuario hasta los principales elementos de la plataforma: almacenamiento, ingesta, transformación, orquestación, análisis de datos y el potencial de la Inteligencia Generativa para ayudarte a dominar la plataforma.

Tanto si te inicias en el mundo del análisis de datos, este libro es para ti.
