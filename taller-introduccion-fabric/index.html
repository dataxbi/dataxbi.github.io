¿Qué aprenderás?

Domina Microsoft Fabric, la plataforma unificada de análisis de datos de Microsoft que integra todas las herramientas necesarias para el procesamiento, transformación y análisis de datos en un solo entorno.

Este taller intensivo te proporcionará las habilidades fundamentales para trabajar con Microsoft Fabric, desde la configuración inicial hasta la implementación de soluciones completas de análisis de datos.

Agenda

Preparación

  • Cada asistente tendrá acceso a un área de trabajo con capacidad Fabric
  • Conexión con GitHub

Arquitectura Medallion

  • Almacenamiento: Lakehouse, Warehouse
  • Ingesta: Acceso directo, Reflejo, Trabajo de copia, Canalización, Python y Spark
  • Transformación: Flujo de datos Gen2, Vistas T-SQL, Vistas Materializadas del Lakehouse, Python y Spark
  • Orquestación: Canalizaciones, Python
  • Modelo semántico: DirectLake

Inteligencia Artificial

  • Creación de un modelo de ML para realizar una predicción
  • Configuración de un agente de datos
