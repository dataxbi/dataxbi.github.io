Descripción

Si trabajas con Power BI, ya conoces Power Query, los modelos semánticos y los informes. Microsoft Fabric amplía ese mundo: un único lago de datos (OneLake), almacenes Lakehouse y Warehouse, herramientas de ingesta y transformación, orquestación y modelos Direct Lake que leen directamente del lago sin importar los datos.

En este taller recorrerás el ciclo completo de un proyecto de datos en Fabric siguiendo la arquitectura medallion (Bronce, Plata y Oro):

almacenamiento → ingesta → exploración → limpieza → modelado

Trabajarás con un caso realista basado en datos de ventas procedentes de una base de datos Azure SQL, ficheros en SharePoint y Azure Data Lake, y una API REST. Al final tendrás un modelo semántico Direct Lake y un informe de Power BI alimentados por un proceso automatizado, construido por ti.

¿A quién va dirigido?

  • Analistas y desarrolladores de Power BI que quieren llevar sus soluciones a Fabric.
  • Responsables de BI que evalúan Fabric para su organización.
  • Profesionales de datos que buscan una visión práctica y completa de la plataforma.

Requisitos previos

  • Experiencia con Power BI Desktop: Power Query, modelo de datos e informes.
  • Recomendable: conocimientos básicos de SQL (SELECT, JOIN, GROUP BY).
  • No se necesita experiencia previa con Python ni Spark.
  • Ordenador con navegador actualizado y Power BI Desktop instalado.
  • No necesitas licencia de Fabric: cada asistente recibe un usuario y un área de trabajo con capacidad Fabric durante el taller.

¿Qué aprenderás?

  • Entender qué aporta Fabric frente a Power BI y cómo se relacionan.
  • Elegir el almacenamiento adecuado (Lakehouse o Warehouse) y organizar los datos con la arquitectura medallion.
  • Ingerir datos con la herramienta más adecuada para cada origen: accesos directos, reflejo (mirroring), trabajo de copia, actividad de copia, Flujos de datos Gen2 y cuadernos.
  • Explorar los datos con SQL, cuadernos y herramientas visuales.
  • Limpiar y transformar datos con Flujos de datos Gen2 (Power Query), T-SQL y Spark.
  • Crear un modelo dimensional y un modelo semántico Direct Lake, y saber cuándo usarlo frente a Import o DirectQuery.
  • Automatizar el proceso con una canalización programada.
  • Conocer las capacidades de IA de Fabric: Copilot y agentes de datos.

Programa

Sesión 1 · Introducción y almacenamiento (3 h)

  • Fabric y el ecosistema de Power BI: inquilino, capacidad, áreas de trabajo, dominios y elementos.
  • Capacidades Fabric, opciones de pago y OneLake como lago de datos único.
  • Parquet, Delta Lake y arquitectura medallion; Lakehouse frente a Warehouse.
  • Práctica: crear los Lakehouses Bronce, Plata y Oro y subir archivos con el explorador de OneLake.

Sesión 2 · Ingesta con accesos directos y copia (3 h)

  • Criterios para elegir la estrategia de ingesta.
  • Accesos directos a SharePoint y Azure Data Lake Storage; de CSV/Excel a tablas Delta.
  • Mirroring de una base de datos Azure SQL en OneLake.
  • Trabajo de copia: carga completa e incremental.

Sesión 3 · Ingesta con transformación y exploración inicial (3 h)

  • Flujos de datos Gen2: transformaciones con Power Query y carga en el Lakehouse.
  • Ingesta desde una API REST con un cuaderno Python guiado.
  • Actividad de copia en canalizaciones.
  • Exploración con T-SQL en el punto de conexión de análisis SQL y el editor visual.

Sesión 4 · Exploración, calidad y transformación Bronce → Plata (3 h)

  • Perfilado con Data Wrangler y revisión de la calidad de los datos.
  • Limpieza con Flujos de datos Gen2 y cargas incrementales.
  • Vistas T-SQL y vistas materializadas de Lakehouse con reglas de calidad.
  • Introducción a Spark con transformaciones generadas por Data Wrangler.

Sesión 5 · Modelado Plata → Oro y Power BI (3 h)

  • Diseño del modelo dimensional: hechos y dimensiones.
  • Construcción de la capa Oro con vistas T-SQL o tablas en un Warehouse.
  • Direct Lake: funcionamiento, comparación con Import y DirectQuery y buenas prácticas.
  • Práctica: modelo semántico en Fabric conectado a un informe de Power BI.

Sesión 6 · Automatización, IA y cierre (3 h)

  • Canalización de extremo a extremo: ingesta, limpieza y modelado.
  • Programación, manejo de errores, alertas y supervisión de la capacidad.
  • Copilot en Fabric y Power BI.
  • Creación de un agente de datos sobre el modelo Oro.
